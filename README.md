# TypeScript Project Standards Template

A minimal starter template for strict TypeScript projects.

## Use

```bash
npm install
npm run check
```

## Files

- `AGENTS.md` — Codex/project agent instructions.
- `tsconfig.json` — strict TypeScript defaults.
- `eslint.config.mjs` — ESLint flat config with type-aware TypeScript rules.
- `src/index.ts` — harmless placeholder so `tsc --noEmit` works in a brand-new repo.

## Notes

This is intentionally framework-light. For Next.js, you may need to merge these rules into the config generated by `create-next-app`.
